So fügst du sie ein

Klick oben auf „Signatur kopieren“ und füg sie dann im Signaturfeld mit Strg+V ein (Mac: ⌘+V).

IONOS oder Strato Webmail
  1. Webmail öffnen (mail.ionos.de bzw. webmail.strato.de) und anmelden.
  2. Oben rechts auf das Zahnrad (Einstellungen) klicken.
  3. E-Mail → Signaturen → Neue Signatur hinzufügen.
  4. Namen vergeben (z. B. „GTS“), Signatur einfügen, speichern.
  5. Als Standard für neue Nachrichten und Antworten auswählen.
Outlook im Web / Microsoft 365
  1. outlook.office.com öffnen und anmelden.
  2. Zahnrad oben rechts → Konten → Signaturen.
  3. Neue Signatur, Namen vergeben, Signatur einfügen.
  4. Unten als Standard für neue Nachrichten und Antworten auswählen → Speichern.
Outlook am PC (Windows)
  1. Datei → Optionen → E-Mail → Signaturen…
  2. Neu klicken, Namen vergeben.
  3. Signatur ins Textfeld einfügen.
  4. Rechts oben die Standardsignatur für neue Nachrichten und Antworten wählen → OK.
Gmail / Google Workspace
  1. Zahnrad oben rechts → Alle Einstellungen aufrufen.
  2. Tab Allgemein → Abschnitt Signatur → Neu erstellen.
  3. Signatur einfügen und darunter als Standard auswählen.
  4. Ganz unten auf Änderungen speichern klicken.
